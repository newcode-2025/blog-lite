# 阶段一后端接口详情

> 文档日期：2026-10-04
> 说明：阶段一共有 8 个公开 GET 接口。下面按接口逐个整理，每个接口的信息都放在该接口自己的小节中，不另外放到文档末尾。

```text
http://localhost:8081
```

统一前缀：

```text
/api/v1
```

统一返回外壳：


## 接口 1：分页查询公开文章

- 接口路径：`GET /api/v1/articles`
- 所在控制器文件：`ArticleController.java`
- 所在控制器类：`ArticleController`
- 是否需要登录：不需要
- 过滤器处理：
  - 会经过 `JwtAuthenticationFilter`，它只做可选的 JWT 认证，不会阻止该接口。
  - 会经过 `ResourceAuthorizationFilter`，它负责接口授权判断；该接口命中公开路径后放行。
  - `SecurityConfig` 对应 GET 路径配置为 `permitAll()`。
  - 是否会被过滤器拒绝：不会。
- 前端参数：
  - `current`：query 参数，可选，页码，默认 `1`
  - `size`：query 参数，可选，每页数量，默认 `10`
- 是否分页：是
- 返回类型：`ApiResponse<PageResultDTO<ArticleCardDTO>>`
- 涉及 DTO：
  - `ApiResponse`
  - `PageResultDTO`
  - `ArticleCardDTO`
  - `TagDTO`
- 作用：分页查询博客首页或文章列表页中的公开文章。
- 业务规则：
  - 只返回 `status = 1` 且 `is_deleted = 0` 的文章。
  - 返回文章摘要、封面、分类、全部标签、置顶和推荐状态。
  - 排序为置顶、推荐、发布时间倒序、文章 ID 倒序。
  - `current < 1` 重置为 1；`size < 1` 重置为 10；`size > 50` 限制为 50。

## 接口 2：查询文章详情

- 接口路径：`GET /api/v1/articles/{id}`
- 所在控制器文件：`ArticleController.java`
- 所在控制器类：`ArticleController`
- 是否需要登录：不需要
- 过滤器处理：
  - 会经过 `JwtAuthenticationFilter`，没有 token 时直接继续。
  - 会经过 `ResourceAuthorizationFilter`，该接口命中公开路径后放行。
  - `SecurityConfig` 对应 GET 路径配置为 `permitAll()`。
  - 是否会被过滤器拒绝：不会。
- 前端参数：
  - `id`：path 参数，必填，文章 ID。
- 是否分页：否
- 返回类型：`ApiResponse<ArticleDetailDTO>`
- 涉及 DTO：
  - `ApiResponse`
  - `ArticleDetailDTO`
  - `TagDTO`
- 作用：查询文章的完整正文、分类和全部标签。
- 业务规则：
  - 只查询公开且未删除的文章。
  - 查询成功后会在事务中执行 `view_count + 1`。
  - 返回的 `viewCount` 是自增后的阅读量。
  - 非数字或小于 1 的 ID 返回业务码 `40000`。
  - 文章不存在或不可公开时返回业务码 `40400`。

## 接口 3：搜索公开文章

- 接口路径：`GET /api/v1/articles/search`
- 所在控制器文件：`ArticleController.java`
- 所在控制器类：`ArticleController`
- 是否需要登录：不需要
- 过滤器处理：
  - 会经过 `JwtAuthenticationFilter`，它只做可选认证，不强制登录。
  - 会经过 `ResourceAuthorizationFilter`，该接口命中公开阅读路径后放行。
  - `SecurityConfig` 对应 GET 路径配置为 `permitAll()`。
  - 是否会被过滤器拒绝：不会。
- 前端参数：
  - `keywords`：query 参数，可选，搜索关键词，默认空字符串
  - `current`：query 参数，可选，页码，默认 `1`
  - `size`：query 参数，可选，每页数量，默认 `10`
- 是否分页：是
- 返回类型：`ApiResponse<PageResultDTO<ArticleCardDTO>>`
- 涉及 DTO：
  - `ApiResponse`
  - `PageResultDTO`
  - `ArticleCardDTO`
  - `TagDTO`
- 作用：按照关键词搜索公开文章。
- 业务规则：
  - 搜索范围包括标题、摘要、正文、分类名称和标签名称。
  - 搜索前会对关键词执行 `trim()`。
  - 空关键词直接返回空分页，不查询数据库。
  - 草稿和软删除文章不会返回。
  - 总数使用 `COUNT(DISTINCT article.id)`，避免多标签造成重复计数。

- 接口路径：`GET /api/v1/categories`
- 所在控制器文件：`CategoryController.java`
- 所在控制器类：`CategoryController`
- 是否需要登录：不需要
- 过滤器处理：
  - 会经过 `JwtAuthenticationFilter`，没有 token 时直接继续。
  - 会经过 `ResourceAuthorizationFilter`，该接口命中公开路径后放行。
  - `SecurityConfig` 对应 GET 路径配置为 `permitAll()`。
  - 是否会被过滤器拒绝：不会。
- 前端参数：无
- 是否分页：否
- 返回类型：`ApiResponse<List<CategoryDTO>>`
- 涉及 DTO：
  - `ApiResponse`
  - `CategoryDTO`
- 作用：查询全部分类，并统计每个分类下的公开文章数量。
- 业务规则：
  - 使用 `LEFT JOIN`，没有公开文章的分类也会返回。
  - `articleCount` 只统计公开且未删除的文章。
  - 排序为 `sort_order ASC`，其次 `id ASC`。

## 阶段一接口统一结论

- 8 个接口全部为 GET。
- 8 个接口全部不需要登录。
- 8 个接口都会经过 `JwtAuthenticationFilter` 和 `ResourceAuthorizationFilter`。
- 真正负责接口资源授权判断的是 `ResourceAuthorizationFilter`。
- 这些接口均命中公开路径规则，因此不会被过滤器拒绝。
- `SecurityConfig` 对阶段一相关 GET 路径配置为 `permitAll()`。
