# 阶段二：用户认证与资料接口详情

> 文档日期：2026-10-04
> 阶段二主要包含注册、登录、退出、当前用户资料。

统一基础地址：

```text
http://localhost:8081
```

统一前缀：

```text
/api/v1
```

统一返回外壳：

```text
ApiResponse<T>
```

> 本文档按接口顺序介绍，每个接口自己的过滤器、登录要求和 DTO 信息都写在该接口小节内。

## 接口 1：用户登录并签发 JWT

- 接口路径：`POST /api/v1/auth/login`
- 所在控制器文件：`AuthController.java`
- 所在控制器类：`AuthController`
- 是否需要登录：不需要
- 过滤器处理：会经过 JwtAuthenticationFilter 和 ResourceAuthorizationFilter；`/api/v1/auth/**` 匿名放行，不会被拒绝。
- 前端参数：
  - LoginRequest JSON 请求体
- 是否分页：否
- 返回类型：`ApiResponse<LoginDTO>`
- 涉及 DTO：
  - `LoginDTO`
  - `LoginRequest`
- 作用：用户登录并签发 JWT
- 业务说明：具体参数校验、权限和返回内容以当前 Controller、Service、Mapper 的实际实现为准。
