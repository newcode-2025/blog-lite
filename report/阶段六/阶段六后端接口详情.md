# 阶段六：媒体上传接口详情

> 文档日期：2026-10-04
> 阶段六包含后台图片上传、批量上传和用户头像上传。

统一基础地址：

```text
http://localhost:8081
```

统一前缀：

```text
/api/v1
```

统一返回外壳：

```text
ApiResponse<T>
```

> 本文档按接口顺序介绍，每个接口自己的过滤器、登录要求和 DTO 信息都写在该接口小节内。

## 接口 1：上传单张图片

- 接口路径：`POST /api/v1/admin/media/images`
- 所在控制器文件：`MediaController.java`
- 所在控制器类：`MediaController`
- 是否需要登录：需要（ADMIN）
- 过滤器处理：会经过 JwtAuthenticationFilter 和 ResourceAuthorizationFilter；未登录 401，非管理员 403。
- 前端参数：
  - file（form-data 文件）、scene（form-data 文本）
- 是否分页：否
- 返回类型：`ApiResponse<MediaUploadResultDTO>`
- 涉及 DTO：
  - `MediaUploadResultDTO`
  - `MultipartFile`
- 作用：上传单张图片或批量上传图片
- 业务说明：具体参数校验、权限和返回内容以当前 Controller、Service、Mapper 的实际实现为准。
